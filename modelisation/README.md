# Brasil Burger - Modelisation

Contenu :
- schema.sql : script de création de la base Postgres utilisée par les trois projets (Java, C#, Symfony).

Comment lancer le projet Java localement :
1. Ouvrir la branche `java`.
2. Aller dans le dossier `java-catalog`.
3. Exécuter `mvn package` puis :
   `java -cp target/java-catalog-1.0-SNAPSHOT.jar com.brasilburger.App`
